# Relaciones POO en Java

Proyecto de consola con ejemplos de relaciones entre objetos. Al ejecutar `src/main.java`, el menú permite elegir:

- **1. Asociación:** empleados relacionados con un banco.
- **2. Agregación:** estudiantes agrupados en departamentos y en un instituto. Los objetos se crean por separado y pueden existir independientemente.
- **3. Composición:** pendiente de implementar.

## Cómo ejecutar

Abre el proyecto en IntelliJ IDEA y ejecuta el método `main` de `src/main.java`. Escribe `1` o `2` en la consola para probar los ejemplos.
